# 🎓 Edemy – Online Learning Website (Frontend Only)

**Edemy** is a simple and modern online learning website. It is made with **React** and **Vite**.  
You can watch YouTube videos and see a list of courses.  
This project does **not** have a backend or real login. It only shows the user interface (UI).

## ✨ What You Can Do

- 👤 See login and register pages (UI only, not real login)
- 🎥 Watch YouTube videos for each course
- 📚 View course list (from a local JSON file)
- 📱 Use on phone, tablet, and computer

## 🛠️ Technologies

- **React** – For building the UI
- **Vite** – For fast development
- **Tailwind CSS** – For styling
- **React Router** – For page links
- **JSON** – For course data (no API)

## 📦 How to Start

### Requirements

- Node.js (version 16 or higher)
- npm

### Steps

# 1. Clone the project
git clone [https://github.com/your-username/edemy](https://github.com/Enesozkan20).git

# 2. Go to the project folder
cd client

# 3. Install packages
npm install

# 4. Start the project
npm run dev

Then open your browser and go to:
👉 http://localhost:5173
